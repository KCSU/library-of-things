Site Manual

Everything that you (hopefully!) need to know to manage the Library of Things website.

0 Getting Started

Since you are able to see this page, you must already be a librarian / administrator and should have access to the admin sidebar on the left.

For each item, you can configure it such that it is lent out for a set duration, or until a specified date, or given away entirely.

Administrators can put out public announcements that will be displayed on the homepage for all users to see. You can do this in the "Settings" section.

Under "Item Requests", you will see all pending requests from users to borrow items. For each loan, you can either confirm item delivery (which will start the timer for the loan) or refuse the request.

Under "Manage Inventory", you will see a list of all items. You can add new items, and also delete and edit existing items. Notably, you can also hide items, which makes them invisible to regular users but still visible in the admin inventory.

Under "Manage Roles", administrators will be able to grant privileges to users.
